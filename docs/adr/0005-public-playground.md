# ADR 0005: Public Playground as a verified replay

- **Status:** Accepted
- **Date:** 2026-07-28

## Context

GeneGIS needs a zero-install public experience, while the analysis engine is a
native Rust workspace with DuckDB and GPU-oriented dependencies. Running that
entire stack on every anonymous browser request would make the first experience
slow, expensive, and operationally fragile.

The public experience must still preserve the core invariant that operations
flow through a `Command` and `GeoWorkflow`, with CRS, units, sources, and
provenance attached. A hand-authored frontend mock would violate that invariant.

## Decision

The public Playground serves a committed **verified replay bundle** generated by
the real Rust pipeline:

1. `run_ask_pipeline` plans and executes the North Star prompt.
2. The result includes the `CommandEnvelope`, executed `GeoWorkflow`,
   `ProvenanceStore`, verification report, dataset/STAC identity, and map.
3. `cargo run -p genegis-analysis --example export_playground -- public/demo`
   exports the browser-safe JSON receipt and PNG.
4. CI regenerates and validates the bundle before building the vinext site.
5. The browser animates the recorded workflow and exposes the complete receipt.

The UI explicitly labels this mode `verified_replay`; it does not imply that an
LLM or native Rust engine is running inside the browser.

## Sharing

The stable query parameter `?demo=nagoya-density` identifies the replay. Opening
that URL loads the same committed receipt and automatically replays the workflow.
No prompt text, secret, or user data is encoded in the URL.

## Consequences

- The public demo needs no API key, database, or long-running native service.
- First interaction is deterministic and completes well within 30 seconds.
- A result cannot drift independently of the Rust engine because CI validates
  command/workflow/provenance identity and regenerates the artifact.
- The public alpha supports a bounded set of samples. Arbitrary live execution
  remains a later deployment track and must retain the same receipt contract.
